# Russian script-style picker

## Build
- Keep the existing Russian typography as the default.
- Add a small downward-arrow control at the upper-right of the Russian page only.
- Open a compact menu with three choices: current style, Устав, and Вязь (the standard Russian spelling of “Yvaz”).
- Apply each choice as a distinct Cyrillic reading treatment while preserving the page’s content, colors, layout, search behavior, and other languages.
- Make the control keyboard-accessible and close it after a choice.

## Verification
- Check all three treatments on Russian desktop and mobile views for readability and overflow.
- Run the Russian wording gate and the full release gate.
