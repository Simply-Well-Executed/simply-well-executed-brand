## Raster exports
The `jpeg/` folder is generated from these vector masters by [the asset export workflow](../../../.github/workflows/export-pentagonal-emblem.yml). All images are independent files. JPEGs use **quality=100 and 4:4:4 chroma sampling**: the lowest practical JPEG compression settings, **not** literally lossless JPEG or 0% compression. For archival or printing, preserve the SVG masters; the workflow also creates lossless PNG variants.
